# dotfiles

My Arch + Hyprland desktop, in one repo: a **quickshell** shell with a
wallhaven-aware wallpaper/palette picker (built on [aether]), an
**AstroVim** config carrying the same palette, and the hyprland / kitty /
foot / GTK / fontconfig glue that keeps every app on the same colours.

Run one script and the whole desktop appears.

[aether]: https://github.com/omacon/aether

---

## What's in here

```
.
├── install.sh              # the one command — see below
├── packages/
│   ├── official.txt        # pacman packages (69), all installed --needed
│   ├── aur.txt             # yay packages (23), same treatment
│   ├── fonts.txt           # font packages, routed repo-then-AUR automatically
│   └── services.txt        # boot services --apps enables (sddm, NetworkManager, ufw)
├── config/                 # → ~/.config/<name>
│   ├── quickshell/         # the shell: bar, picker, settings, services, scripts
│   ├── hypr/               # lua config (binds, rules, appearance, generated colours)
│   ├── nvim/               # AstroVim — colourscheme wired to the shell palette
│   ├── themes/             # 24 themes: colours.toml + preview.png + backgrounds
│   ├── kitty/ foot/        # terminals
│   ├── gtk-3.0/ gtk-4.0/   # GTK theme + settings (set-font.sh patches these)
│   ├── fontconfig/         # fonts.conf (generated by set-font.sh)
│   └── aether/ btop/ fastfetch/ mpv/ cliamp/ xsettingsd/ nwg-look/ ...
├── local/bin/              # → ~/.local/bin (aspect-fit.sh, screenshot.sh, xunhide, ...)
├── local/share/            # → ~/.local/share (the SDDM greeter's staged theme)
├── wallpapers/             # → ~/Wallpapers (real files; theme links are rebuilt)
└── state/quickshell/       # settings + current font/theme/gtk, seeded on first run
```

Roughly **159 MB / 495 files** — almost all of it is theme wallpapers.

## Installing

Fresh Arch box (needs `git`; `sudo` for `--apps`):

```bash
git clone <this-repo> ~/.dotfiles
cd ~/.dotfiles
./install.sh --apps        # packages + boot services + configs + theme + greeter
./install.sh               # configs only, no sudo — safe to re-run any time
./install.sh --dry-run     # show exactly what would happen, change nothing
```

`--apps` passes `--needed` to both `pacman` and `yay`, so nothing you already
have is reinstalled or downgraded. It bootstraps `yay` if it's missing, then
**enables the boot services** in `packages/services.txt` — a fresh Arch leaves
`sddm`, `NetworkManager` and `ufw` preset-disabled, so without that step you'd
be at a TTY instead of a login screen — and finally installs the SDDM greeter's
root copy (`selah-sddm.sh set selah`).

Order of operations: packages → boot services → symlinks → wallpapers → state
seeds → font → active theme → SDDM greeter → astro plugin sync (skippable with
`--skip-nvim`).

None of it needs a display: the theme step degrades cleanly from a bare TTY
("hyprctl reload: no running Hyprland — colors apply next start"), and the GTK
choice comes from the seeded `state/quickshell/current-gtk-theme` when dconf
has nothing to say yet. Run `./install.sh` once more after your first login to
push the theme into `gsettings`/dconf while a session exists.

### How the symlinks work

The repo owns the real files; `~/.config` entries become pointers into it.

```
~/.dotfiles/config/quickshell/Bar.qml  ← real bytes, the only copy
~/.config/quickshell/Bar.qml       ← arrow into the repo
```

So both paths are the same file:

| You do | Result |
|---|---|
| `git pull` | the desktop updates in place — nothing to re-run |
| edit `~/.config/quickshell/Bar.qml` | you edited the repo; `git diff` shows it |
| `switch-theme.sh` writes `~/.config/hypr/colors.lua` | lands in the repo, gitignored as a generated file |

Anything already at a destination is **moved** to
`~/.dotfiles-backups/<timestamp>/` first — never deleted, and repeated runs
never collide. `--dry-run` previews all of it.

### What is deliberately *not* committed

| Left out | Why |
|---|---|
| `~/.local/share/fonts` (1.2 GB) | personal font library; `packages/fonts.txt` installs the families the desktop needs |
| `~/.config/nvim/.git` | AstroNvim's template clone would become a gitlink here — this repo owns the config now; plugins still update via `:Lazy sync` |
| `*.bak`, `__pycache__` | git is the history |
| `hypr/colors.lua`, `kitty/current-theme.conf`, `gtk-3.0/theme.css` | regenerated on every theme apply (and by `install.sh`) |
| `~/.local/state/quickshell` runtime | battery history, clipboard, weather cache — only the settings seeds ship |
| `~/Wallpapers/<theme>--*.jpg` | symlinks rebuilt by `scripts/seed-wallpapers.sh` |
| `/usr/share/sddm/themes/selah`, `/etc/sddm.conf.d/selah.conf` | root copies, rebuilt by `install.sh --apps`; the *staged* greeter source is committed under `local/share/` |
| `local/share/sddm/wayland-session.log` | dropped there by sddm at every login |

## Everyday commands

The shell does most of this itself; these are the manual escape hatches.

```bash
cd ~/.config/quickshell

scripts/switch-theme.sh <name>     # apply a theme: shell + hypr + kitty + GTK + wallpaper
scripts/set-font.sh "<family>"     # fontconfig + gsettings + GTK + kitty, live (45 ms)
scripts/set-text-size.sh 13        # same story for size
scripts/seed-wallpapers.sh         # rebuild ~/Wallpapers links from theme backgrounds
scripts/generate-previews.sh       # re-shoot theme selector thumbnails
scripts/theme-manage.py            # rename/delete themes (validates paths, blocks active)

# optional, one-time: passwordless greeter switching from the settings app
# (installs /usr/local/sbin/selah-sddm + a NOPASSWD drop-in for just it)
scripts/selah-sddm.sh setup-help
```

Theme browsing lives inside the shell: **`SUPER + ALT + W`** opens the picker,
with wallhaven (search / toplist / latest / random) reachable in the carousel
overlay rather than a separate window.

Everything above is a symlink into this repo, so `git status` in
`~/.config/quickshell` works exactly like here.

## Portability

Written for one machine, so a few things assume this user and hardware:

| Thing | Note |
|---|---|
| `/home/jordanzo` in 7 files | `fastfetch` logo, `selah-sddm.sh` state path (it *wants* your home even as root), `aether` blueprint + `.aether-generated` provenance markers, `state/current-wallpaper`. Change the user and search for it. |
| `packages/aur.txt` | your machine's AUR set — `nvidia-470xx-dkms` is GPU-specific, `*-debug` entries are build artifacts. Trim for other hardware. |
| `monitors.lua` | `1920x1080@60.06Hz` on `output = ""` |
| `autostart.lua` | starts `megasync` (your backups) |
| `~/.local/bin` | deliberately not on `PATH` — hyprland binds call those by full path |

Everything else (shell, themes, fonts, terminals, hyprland) is user-agnostic.

## Updating this repo

```bash
cd ~/.dotfiles
git add -A
git commit -m "what changed"
git push
```

New files are picked up automatically on `git add -A`; if you add a *new*
directory under `config/`, the next `./install.sh` links it too.
